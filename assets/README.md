# ThermoSlop logo

The mark is the panel's ring gauge with a drip falling off it: a thermostat,
plus slop.

| File | Use |
|---|---|
| `thermoslop-logo.svg` / `.png` | Wordmark lockup on its navy tile (README, social preview). The text is outlined, so no font is needed. |
| `thermoslop-icon.svg`, `-512.png`, `-128.png` | App/avatar icon: the mark on a rounded navy tile |
| `thermoslop-mark.svg` | The mark alone, for light or dark backgrounds |
| `thermoslop-mark-mono.svg` | One color (`currentColor`), for bars, menus and favicons |

Colors: navy `#0b1d33`, orange `#faa968`, cream `#f6dcac`. Wordmark: JetBrains
Mono, "Thermo" regular in cream and "Slop" bold in orange.
